# Signpair Whitepaper

## Vision

Markets on Solana move faster than any single chart can follow. Signpair's vision is a calm surface over that speed: every active token shown beside its own numbers, ranked by what is actually changing hands, with nothing invented along the way.

## Mission

Make market activity legible. Signpair publishes only what its sources confirm, marks everything else as pending, and keeps the line between the two visible to anyone who looks.

## Principles

- **Confirmed or inert.** Every external fact lives in one register. A fact is stated, absent or unconfirmed, and anything not stated stays inactive on the page.
- **No invented figures.** Numbers on the site come from the live feed or are left blank.
- **Motion with manners.** Animation is optional. Reduced-motion settings turn all of it off.

## Roadmap

### Phase 1: Foundation

Public site, live board, ticker and the registry of confirmed facts.

### Phase 2: Launch

The contract address is published and every slot that was waiting switches on. Social channels and the code repository are linked as they are confirmed.

### Phase 3: Signals

Richer reads on each pair: flow, depth shifts and holder concentration.

### Phase 4: Open tools

Public code and a documented interface so others can build on the same board.
